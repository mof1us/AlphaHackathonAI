# Репозиторий решения хакатона

### elaboration - директория проработок
Это директория, которая хранит в себе знания о продукте для дальнейшего их использования при составлении презентации и подготовке к защиете.

Проработки следует писать в файлах `README.md` в отдельных дерикториях с разметкой Markdown.

### frontend/backend
Основные исполняемые модули системы. 

- Frontend - Next.js приложение
- Backend - Spring Boot монолит

Подробнее см [в проработке](elaboration/architechure/README.md)

### docker compose
Исполняемый файл docker compose для запуска приложения. 

### .github
Здесь будут конфиги CI

CI в данном хакатоне сделаем простым - просто прогон тестов и сборка docker образов с деплоем их в docker hub

Перезапускать будем вручную на сервере
